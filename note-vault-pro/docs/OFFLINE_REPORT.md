# Offline report
Shell, fonts, icons, PDF.js + worker are bundled; data is in IndexedDB. `public/sw.js` (hand-written, same-origin only) precaches the shell, falls back to cached index.html on navigation, cache-first for assets, prompts the user before applying updates. VERIFIED with Playwright/Chromium + `setOffline(true)`: reload offline, create/edit a note offline, text survives reload. NOT verified: device installation (Android/iOS/desktop), eviction behaviour. Constraint: the build is a single `dist/index.html` (vite-plugin-singlefile, config not editable); if a host serves only that file, the service worker/installability are unavailable. Workbox/vite-plugin-pwa could not be used for that reason.
