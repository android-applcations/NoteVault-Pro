# Database
Dexie `notevault-pro`, schema v1, 25 tables (semesters, subjects, lectures, notes, noteVersions, attachments, blobs, pdfDocuments, bookmarks, highlights, annotations, flashcardDecks, flashcards, reviewLogs, quizzes, quizQuestions, quizAttempts, references, tags, noteTags, searchIndex, activities, appSettings, trashItems, events). UUID ids, createdAt/updatedAt, indexed foreign keys, binary data only in `blobs` (reference-counted, shared by linked/duplicated attachments). Soft delete (`deletedAt`+`trashId`) for subjects/lectures/notes/attachments with cascade restore/purge; related writes in transactions. Add migrations via `db.version(n).upgrade()`; `DATA_VERSION` is checked on import. Cards/decks/quizzes/references/events are hard-deleted after confirmation.
